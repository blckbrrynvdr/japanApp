Dev plan — Japan Trip Planner v2

Цель
- Преобразовать приложение из заметочника в персональный путеводитель по поездке.
- Пересобрать JSON-конфиг как финальную версию v2 и расширить модель данных.
- Сохранить текущую архитектуру Angular + Taiga UI, но добавить более содержательные поля и улучшить отображение маршрута.

Текущее состояние (выполнено)
- Angular проект и Taiga UI настроены.
- `src/app/models.ts` расширен новым типом `TripPoint` и дополнительными полями маршрута.
- `src/assets/trip-config.json` обновлен до v2-версии, успешно парсится как JSON.
- `ScheduleItemComponent` отрисовывает новые поля: тип, длительность, стоимость, приоритет, статус, бронь, зависимость от погоды, карта и заметка.
- `DayCardComponent` вычисляет день недели по `day.date`.
- `npm run build` проходит успешно.
- `ng serve` работает на `http://127.0.0.1:4200`.
- Документация переведена в папку `docs/`.
- `README.md` уже содержит ссылки на `docs/` и GitHub Pages.

Задачи
1. Завершить и согласовать содержимое v2-конфига `src/assets/trip-config.json`:
   - актуальные локации и маршруты, включая Gotokuji, Yanaka, KITTE Garden, Ochanomizu, Nakano, отправку багажа, Universal, Нара.
   - подробные описания, примерные длительности, приоритеты, бронирования, статусы и теги.
2. При необходимости доработать UI и компоненты для удобства отображения путеводителя:
   - фильтрация по типу/тегам/статусам;
   - модальное окно для деталей маршрута;
   - дополнительные поля `personalNote` и карточки дня.
3. Обновить документацию проекта после окончательного утверждения структуры.

Примечания
- `docs/dev-plan.md` является единственной действующей версией плана.
- Файл `dev-plan.md` в корне проекта удален, чтобы избежать дублирования.

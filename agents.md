# Agents Overview

## Цель проекта
Создать пользовательский интерфейс для планирования поездки в Японию на Angular с использованием Taiga UI.

## Структура данных
Всё содержимое приложения загружается из одного JSON-конфига `src/assets/trip-config.json`.

Основные поля конфига:
- `appContext` — пояснение и описание поездки.
- `agentInstructions` — инструкции для будущих AI-агентов.
- `days` — массив дней маршрута.
- `budget` — бюджет и категории расходов.
- `payments` — записи о платежах и статусах.
- `shopping` — покупки, лимиты и прогресс.
- `souvenirTips` — текстовые заметки по сувенирам.
- `checklist` — список дел и бронирований.
- `links` — полезные ссылки.

## Компоненты
- `App` — корневой standalone-компонент.
- `DayCardComponent` — карточка дня маршрута.
- `ScheduleItemComponent` — элемент расписания внутри дня.
- `BudgetComponent` — таблица бюджета.
- `PaymentsComponent` — список оплаченных и запланированных расходов.
- `ShoppingComponent` — покупки с лимитом и прогрессом.
- `SouvenirTipsComponent` — текстовые советы о сувенирах.
- `ChecklistComponent` — чеклист бронирований.
- `LinksComponent` — список полезных ссылок.

## Архитектурные особенности
- Angular standalone components
- Сервис `ConfigService` загружает JSON-конфиг через HTTP клиент.
- Типы данных описаны в `src/app/models.ts`.
- Внешняя библиотека UI: Taiga UI.
- Стиль приложения из `src/styles.less` подключает Taiga UI theme.

## Текущий статус
- Angular проект и Taiga UI настроены.
- Компоненты зарезервированы и интегрированы в шаблон приложения.
- Конфиг загружается из JSON.
- Необходимо исправить запуск dev server и поддержку статического релиза.

## Дальнейшие шаги для агентов
1. Исправить базовую конфигурацию Taiga UI: добавить `provideTaiga()`.
2. Добавить `src/assets` в `angular.json` как ассетную папку.
3. Обеспечить относительные пути в `index.html` для статического просмотра.
4. Улучшить UI, добавить диалог детального просмотра, превью фото и полноценную карточную вёрстку.
5. Реализовать будущую функциональность редактирования конфига.
